# Molecular Visualization System

A frontend web application for interactive 3D visualization and structural validation of chemical molecules.

Built with **JavaScript**, **React**, **Three.js**, **React Three Fiber**, and **Vite**.

## Features

- 3D molecular structure visualization.
- Atom and chemical bond rendering.
- JSON-based molecular data.
- Interactive 3D scene navigation.
- Structural validation of molecular data.
- Responsive user interface.

## Requirements

- Node.js
- npm

## Installation

```bash
npm install
```

## Available Commands

**Start development server:**

```bash
npm run dev
```

**Start development server with network access:**

```bash
npm run dev -- --host 0.0.0.0
```

**Run ESLint:**

```bash
npm run lint
```

**Build for production:**

```bash
npm run build
```

## Technologies

- React
- JavaScript (ES6+)
- Three.js
- React Three Fiber
- Vite
- HTML5 / CSS3

## Project Scope

This project focuses exclusively on the frontend implementation. Molecular structures are loaded from predefined JSON files containing atom coordinates and chemical bond information. Full molecular generation and advanced chemical validation are outside the current scope.
